Frequently Asked

How to reset password?

Go to login page → Click "Forgot Password" → Enter your email → Check your inbox for reset link.

How to change profile picture?

Settings → Account → Avatar → Upload new image → Save changes.

How to enable notifications?

Settings → Notifications → Enable desired notification types → Save preferences.

Data backup and export?

Privacy Settings → Download My Data → Request backup → Receive email with download link.
